## Why this matters

Node.js 18 reached End-of-Life on April 30, 2025 — over 16 months ago. It no longer receives security patches. The Dockerfile pins `node:18.19.1-alpine`, CI uses Node 18, and `package.json` declares `engines: node >=18.0.0`. Running on an EOL runtime exposes the server to unpatched vulnerabilities. **Node.js 24 is the current Active LTS** (since October 2025, supported until April 2028). The original plan targeted Node 22, but Node 22 entered Maintenance LTS in October 2025 and reaches EOL in April 2027 — only ~7 months of runway remain, so jumping straight to Node 24 is the better investment.

## Steps

### Step 1: Update Dockerfile base image

Change line 2 from:
```dockerfile
FROM node:18.19.1-alpine
```
to:
```dockerfile
FROM node:24-alpine
```

Using `node:24-alpine` (without a specific patch version) pulls the latest Node 24 LTS Alpine image. This is preferable to pinning a specific patch for the base image since Node 24 LTS patch releases are security updates. If reproducibility is critical, pin to a specific tag like `node:24.x.y-alpine` — but check Docker Hub for the latest available tag before pinning.

**Verify**: Read `Dockerfile` line 2 and confirm it says `FROM node:24-alpine`.
