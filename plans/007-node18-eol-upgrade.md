## Why this matters

Node.js 18 reached End-of-Life on April 30, 2025 — over 14 months ago. It no longer receives security patches. The Dockerfile pins `node:18.19.1-alpine`, CI uses Node 18, and `package.json` declares `engines: node >=18.0.0`. Running on an EOL runtime exposes the server to unpatched vulnerabilities. Node.js 22 is the current Active LTS (as of 2026-07-16) and will be supported until April 2027.

## Steps

### Step 1: Update Dockerfile base image

Change line 2 from:
```dockerfile
FROM node:18.19.1-alpine
```
to:
```dockerfile
FROM node:22-alpine
```

Using `node:22-alpine` (without a specific patch version) pulls the latest Node 22 LTS Alpine image. This is preferable to pinning a specific patch for the base image since Node 22 LTS patch releases are security updates. If reproducibility is critical, pin to a specific tag like `node:22.11.0-alpine` — but check Docker Hub for the latest available tag before pinning.

**Verify**: Read `Dockerfile` line 2 and confirm it says `FROM node:22-alpine`.
